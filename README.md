# CH14 – Loan Portfolio Insight

## Project Overview
This project analyzes loan repayment behaviour to identify customer and loan characteristics associated with repayment difficulties.

## Objectives
- Understand and clean loan portfolio data.
- Analyze repayment patterns using exploratory data analysis.
- Build a machine-learning model to classify repayment difficulty.
- Create visualizations and an Excel analysis workbook.
- Provide data-driven recommendations for portfolio monitoring.

## Datasets
- `loans.csv` – Loan details
- `customers.csv` – Customer characteristics
- `payments.csv` – Payment records
- `accounts.csv` – Account information
- `history.csv` – Previous repayment history

**Note:** The practice dataset is synthetic and is not official company data.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab
- Microsoft Excel

## Machine Learning
**Algorithm:** Random Forest Classifier

**Target:** Repayment difficulty

Actual evaluation metrics are available in `outputs/model_metrics.csv`.

## Visualizations
- Repayment difficulty by loan type
- Repayment difficulty by income band
- Repayment difficulty by loan tenure
- Repayment difficulty by previous delays
- Regional comparison
- Confusion matrix
- Feature importance

## Project Files
- `CH14_Loan_Portfolio_Insight.ipynb` – Project notebook
- `outputs/` – Excel workbook and model results
- `data/` – Dataset documentation

## Conclusion
The project demonstrates a data-science workflow for cleaning loan portfolio data, exploring repayment patterns, evaluating a classification model, and preparing reports to support portfolio monitoring.
